# 会話の利用者向けの案内

開発環境の紹介だけでは、会話アプリへ来た人が登録や操作を始められなかったため、初期内容に利用者向けの案内を追加する。最初の登録、日々の会話、部屋の作成、招待、本人確認、困ったときの順に読む経路を用意する。開発用の説明は引き続き別の記事として残す。[[content-ownership]]。

紹介サイトの編集者と会話アプリの参加者は別管理であること、初回登録の鍵も別であることを明示する。本文は実装済みの操作だけを説明し、個別の会話や非公開の部屋など未実装の機能を利用可能とは表現しない。

初期内容の再投入で、既に編集された本文や公開状態を上書きしない。新規の環境では使い方を含む一式を投入し、既存の環境には不足する説明だけを追加する。既存のトップ本文を新しい内容に差し替える場合は、管理画面から確認して更新する。

最新版の検索・小容量添付・チャンネルの名前変更とアーカイブ・表示名変更に案内を合わせる。添付の容量制限と変更不可の範囲、検索の続きと終了状態を説明する。初期内容の追加と編集者の既存内容保持を両立し、自動的な本文上書きは採用しない。検証は [[verification]] に従いローカルの公開経路と編集後の再投入で確認する。本番の内容更新はこの統合作業に含まない。
