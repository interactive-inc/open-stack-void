# 外部クライアントの権限

CLI と MCP に別の業務実装を持たせると、権限や失敗時の挙動がずれる。共通クライアント経由でアプリに操作を依頼する。

パスキーを端末プログラムに渡さないため、ブラウザでログインした本人が期限付きトークンを発行する。CLI が秘密値を受け取る場合は、利用者の明示操作によるクリップボードだけを使う。ターミナルへの入力や表示、コマンド引数、平文の設定ファイルを避ける。停止時にはトークンが残っていてもアクセスを拒否する。

クリップボードは自動消去しない。後からコピーされた内容を壊さず、繰り返し操作を可能にするため。OS の履歴や同期の消去をアプリが保証する設計にはしない。

MCP はローカルの標準入出力を使う。HTTP MCP と OAuth は信頼境界が異なるため、この接続方式のまま外部公開しない。[[chat-security]]。
